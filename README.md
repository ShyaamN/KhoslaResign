# KhoslaResign

Independent campaign site calling on the UC Board of Regents to remove UC San Diego Chancellor Pradeep K. Khosla — or for him to resign.

## Stack

- Vite + React + TypeScript
- Client-side signatures via `localStorage` (plus a small seeded demo set)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Note

This project is not affiliated with UC San Diego or the UC Regents.
